Play songs directly from your device storage.

### Supported Features
- ▶️ Play / Pause
- ⏭ Next / Previous

- 🔀 Shuffle Playback
- 🎚 Seek Bar Support

- 🔒 Lockscreen Controls

---

# 🌐 M3U Streaming

NeuroBeat supports online audio streaming using `.m3u` playlist files.

## How To Use

### Step 1
Download an M3U playlist.

### Step 2
Open NeuroBeat.

### Step 3
Navigate to:

```text
Streaming Section
```

### Step 4
Select your `.m3u` file.

### Step 5
Enjoy online streaming instantly.

---

# 📂 Supported Playlist Types

- `.m3u`
- `.m3u8`
